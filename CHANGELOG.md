# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-03-01
### Added
- Python packaging metadata and installable `src` layout configuration.
- Automated GitHub Actions pipelines for linting, testing, security scanning, and release publishing.
- Runtime system monitoring utilities with Raspberry Pi fallbacks.
- Comprehensive documentation covering usage, configuration, CI/CD, and release procedures.
- Unit tests for `RiskManager` and `ConfigManager` to safeguard core trading logic.

### Changed
- Simplified runtime and development dependency declarations.
- Updated README and Makefile to reflect production-ready workflows.
